# 01 - Acesso, Tela Inicial e Dashboard

## Objetivo deste módulo

Este módulo serve para entrar no Portal SGO+, identificar se a sessão está correta, navegar pelo menu e acompanhar o resumo operacional.

## Antes de comecar

Você precisa ter usuário cadastrado, senha ativa, perfil liberado e internet. Se não souber usuário ou senha, fale com o administrador.

## Como entrar

1. Abra o link do portal.
2. Digite `Usuário`.
3. Digite `Senha`.
4. Clique em `Entrar`.
5. Aguarde a tela principal carregar.

Se apertar Enter no usuário, o cursor vai para a senha. Se apertar Enter na senha, o sistema tenta entrar.

## Se o login falhar

- Confira usuário e senha.
- Verifique se não digitou espaco antes/depois.
- Se aparecer permissão negada, o usuário pode estar inativo.
- Se a tela ficar travada, atualize a pagina.
- Se continuar, chame o administrador.

## Entendendo a tela principal

A tela tem topo, menu lateral, barra de avisos e área de conteúdo.

No topo ficam logo, relogio, status produtivo, usuário e botao `Sair`.
No menu ficam Dashboard, módulos técnicos, cadastros, documentos, admin e sincronização OS+.
Na área de conteúdo abre o módulo escolhido.

## Dashboard

O Dashboard mostra resumo de clientes, unidades, equipamentos, documentos e alertas de vencimento.

### Como interpretar alertas

- Sem alertas: não há vencimentos proximos.
- Atenção: documento perto de vencer.
- Critico: documento vencido.

Quando houver alerta, abra `Documentos`, pesquise o registro e confira se precisa renovar.

## Ociosidade

Se o sistema ficar parado por muito tempo, pode mostrar alerta. Clique para retomar ou faca login de novo.

## Sair corretamente

Clique em `Sair`, aguarde voltar para login e feche o navegador se estiver em computador compartilhado.

## Duvidas frequentes

### Não vejo todos os módulos
Seu perfil pode não ter permissão.

### O dashboard parece desatualizado
Atualize a pagina e confira se os registros estao ativos.

### Módulo técnico não abre
Ele pode ser um iframe externo. Atualize a pagina; se persistir, avise suporte.
