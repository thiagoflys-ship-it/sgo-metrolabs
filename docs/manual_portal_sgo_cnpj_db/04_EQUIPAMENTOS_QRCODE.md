# 04 - Módulo Equipamentos e QR Code

## Para que serve

Este módulo registra os equipamentos atendidos pela empresa e permite gerar QR Code para identificação física. O cadastro correto evita erro em relatório, auditoria, planejamento e documentos.

## Antes de cadastrar

Tenha em maos cliente, unidade, tipo de equipamento, marca, modelo, número de série, patrimonio ou TAG, local de instalacao e situação do equipamento.

## Campos principais

- `Cliente`: dono do equipamento.
- `Unidade`: local onde o equipamento está instalado.
- `Tipo`: autoclave, lavadora, termodesinfectora, incubadora, seladora, entre outros.
- `TAG / Patrimonio`: código interno usado pelo cliente.
- `Marca` e `Modelo`: identificação do fabricante.
- `Número de série`: dado essencial para rastreabilidade.
- `Localização`: setor, sala ou área onde o equipamento fica.
- `Status`: ativo, inativo ou situação equivalente.

## Pesquisar equipamento

1. Abra `Equipamentos`.
2. Filtre por cliente ou unidade.
3. Digite TAG, série, modelo ou local.
4. Clique em `Pesquisar`.
5. Confira se o equipamento já existe antes de criar outro.

## Cadastrar equipamento

1. Clique em `+ Novo Equipamento`.
2. Escolha o cliente.
3. Escolha a unidade.
4. Informe tipo, TAG, marca, modelo e série.
5. Preencha localização e observações quando existirem.
6. Clique em `Salvar`.
7. Pesquise novamente para confirmar.

## Editar equipamento

1. Pesquise o equipamento.
2. Clique em `Editar`.
3. Corrija os dados.
4. Clique em `Salvar`.

## Gerar QR Code

1. Pesquise o equipamento.
2. Abra a ação de `QR Code`, `Etiqueta` ou opção equivalente.
3. Confira se o QR mostra o equipamento certo.
4. Gere ou imprima a etiqueta.
5. Cole a etiqueta no equipamento em local visível, limpo e protegido.

## Como conferir antes de imprimir

Veja se cliente, unidade, TAG, série e equipamento batem com a placa física. Se alguma informação estiver errada, corrija o cadastro antes de imprimir.

## Problemas comuns

### O QR Code abre equipamento errado

Não use a etiqueta. Gere novamente depois de corrigir o cadastro.

### Equipamento não aparece

Confira cliente, unidade, status e filtros de busca.

### Série não existe na placa

Use TAG ou patrimonio como referencia, mas registre em observações que a série não foi encontrada.
