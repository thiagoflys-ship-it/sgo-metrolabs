# 14 - Sincronização com OS+

## Para que serve

O botao `SINCRONIZAR COM OS+` exporta a base atual do portal para o sistema OS+. Ele atualiza clientes, TAGs/equipamentos e usuários no sistema novo.

## Quem deve usar

Somente diretoria, administrador ou pessoa autorizada. Essa ação pode impactar outro sistema.

## Antes de sincronizar

Confira:

- Clientes principais estao corretos.
- CNPJs não estáao duplicados.
- Unidades estao vinculadas aos clientes certos.
- Equipamentos importantes estao com TAG/série corretas.
- Usuários estao ativos ou inativos corretamente.
- Não há cadastro de teste misturado com base real.

## Como executar

1. Abra o portal.
2. No menu, localize `SINCRONIZAR COM OS+`.
3. Clique no botao.
4. Leia o aviso de diretoria.
5. Se tiver certeza, confirme.
6. Aguarde o processamento terminar.
7. Confira a mensagem final.

## Se aparecer erro

Não clique varias vezes seguidas. Anote a mensagem, horario e usuário que executou. Depois avise suporte ou diretoria.

## Depois da sincronização

Entre no OS+ e confira alguns registros importantes:

- Um cliente novo.
- Uma TAG/equipamento alterado.
- Um usuário alterado.

Essa conferencia simples evita descobrir problema apenas quando a equipe precisar usar.

## Cuidados importantes

- Não sincronize no meio de cadastro incompleto.
- Não sincronize se perceber duplicidade grande na base.
- Não sincronize para testar curiosidade.
- Se houver dúvida, pare e chame o responsável.
