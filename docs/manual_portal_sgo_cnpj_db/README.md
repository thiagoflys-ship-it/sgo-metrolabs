# Manual Operacional do Portal SGO+ CNPJ/DB

Este conjunto de manuais foi escrito para usuário leigo. A ideia e que uma pessoa consiga abrir o módulo, seguir o passo a passo e entender o que fazer quando aparecer dúvida, erro ou resultado inesperado.

## Como usar estes manuais

1. Comece pelo manual de acesso e dashboard se você nunca entrou no sistema.
2. Use o manual do módulo especifico quando estiver executando uma tarefa.
3. Em módulos técnicos por iframe, leia também o manual da aba interna: Template ou Relatório.
4. Antes de excluir, inativar, reativar ou gerar documentos oficiais, confira os dados com calma.
5. Quando houver reprovação técnica, alerta critico, dado estranho ou arquivo incorreto, pare e chame o responsável técnico.

## Regras de ouro

- Não cadastre cliente duplicado. Pesquise por CNPJ antes.
- Não cadastre unidade sem escolher o cliente correto.
- Não cadastre equipamento sem TAG, série ou localização quando esses dados existirem.
- Não gere documento oficial sem revisar cliente, CNPJ, equipamento, data e status.
- Não use ajuste técnico para transformar reprovação em aprovação.
- Não exclua registros se a intencao for apenas parar de usar. Prefira inativar.
- Em caso de dúvida técnica, registre a dúvida e chame engenharia/metrologia.
