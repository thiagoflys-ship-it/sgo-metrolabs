# 10 - Lavadora - Gerar Template

## Para que serve

Este módulo prepara o template para ensaio de lavadora ou termodesinfectora. O template organiza cliente, equipamento, programa, sensores e parametros de avaliação.

## Antes de comecar

Tenha cliente, CNPJ, unidade, equipamento, TAG, marca, modelo, série, programa de lavagem, lote, responsável técnico, operador e quantidade de sensores.

## Passo a passo

1. Abra `Lavadoras` no menu do portal.
2. Entre na aba `Gerar Template`.
3. Preencha cliente ou instituição.
4. Informe CNPJ e use busca quando existir.
5. Confira unidade e endereço.
6. Informe programa/receita do equipamento.
7. Escolha tipo de ensaio.
8. Preencha ciclo, TAG, marca, modelo e série.
9. Informe lote, localização, responsável técnico e operador.
10. Preencha equipamento a validar e temperatura alvo.
11. Informe quantidade de sensores.
12. Revise os dados.
13. Gere o template.

## Pontos de atenção

Lavadoras podem ter programas diferentes: limpeza, termodesinfeccao, enxague, secagem ou ciclos especificos do cliente. O nome do programa precisa representar o ciclo real executado.

## Conferencia antes de gerar

Confira equipamento, série, programa, temperatura alvo e quantidade de sensores. Erro nesses dados gera analise errada no relatório.

## Problemas comuns

### Programa não aparece na lista

Use o campo manual, se existir, ou escreva exatamente como o cliente identifica o programa.

### Temperatura alvo está em dúvida

Confirme no protocolo, manual do equipamento ou com o responsável técnico.

### Template ficou com dados antigos

Limpe o formulario ou atualize a pagina antes de gerar outro.
