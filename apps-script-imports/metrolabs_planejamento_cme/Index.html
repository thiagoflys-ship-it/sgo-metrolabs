Assistente guiado para orçamento e planejamento técnico.
Manual do Operador

1. Dados do cliente

Preencha o CNPJ para tentar o preenchimento automático. Se a consulta não funcionar, continue preenchendo manualmente.

2. Dados do equipamento

Informe os dados essenciais da máquina. O volume da câmara será usado para definir a quantidade de sensores.

3. O que foi vendido?

Marque exatamente o que foi contratado. O sistema vai orientar o cálculo com base nas escolhas.

4. Receitas que serão qualificadas

Informe as receitas que o cliente deseja qualificar. Exemplos: Instrumental, Têxteis, Príons, Lavagem Geral.
Como as Qualificações de Operação e Desempenho não foram marcadas, não é necessário informar receitas nesta etapa.
Calculando e gerando a fundamentação técnica com IA — pode levar alguns segundos...

5. Resultado do planejamento

O sistema calculou o quantitativo com base no volume da câmara, no escopo selecionado e nas referências normativas aplicáveis.
